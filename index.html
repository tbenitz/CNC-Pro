3D model → wood relief

Upload STL (binary/ASCII) or triangulated OBJ. The app projects the top-facing mesh onto an editable-height relief, then uses the existing ball/flat bit raster CAM. This is 2.5D only—no undercuts, sides, rotary axes or actual part separation.

STL and OBJ have ambiguous units. Check stock size, orientation, model width/length and relief depth in Job setup after loading.

CNC Pro · How to use it

1 · Set your machine and stock. On Job setup, confirm your actual usable X/Y machine travel. Enter raw stock width X, length Y, and thickness, and offsets if you want an envelope fit check. CNC Pro defines the stock lower-left as work X0 Y0, with Z0 at the top surface. A generated negative Z cuts down into the stock. Physically set matching work zeros on your machine before running any exported file.

Studio v4 · Vector assets, raised map relief, imported 3D/photo relief, pocketed frame and guided AI. The Design tab contains a searchable library of editable symbols, shapes, botanical motifs, frames, patterns and monogram letters. Double-click an asset or select and insert. AI Design now asks DeepSeek to select a guided composition made from validated local vector motifs. A no-key local scene composer is also included. Review before applying. The Frame builder generates an actual central pocket and outside profile with holding skin, rather than three outline grooves. DeepSeek does not create trusted machine-ready G-code. Transform lets you rotate/mirror/center, make arrays and insert stroke lettering. The API key is never included in a project/G-code export.

2 · Make or import geometry. Draw a rectangle/circle or multi-point path in the top view, or import SVG/DXF. Select each object and choose engrave centerline, outside profile, inside profile, or pocket; set final depth per object. Drag objects to reposition them. Vector imports expect millimeter-scale coordinates; check and adjust after loading.

3 · Configure the bit. Enter bit type, diameter, depth per pass, stepover, feed, plunge, safe height, and spindle RPM command. Profiles include geometric compensation of the bit center; pockets are raster cleared and boundary finished on individual depth passes. These are simple 2.5D strategies; no automatic holding tabs or ramp/lead-in planning. Do not cut through clamped stock without an appropriate spoilboard/holding plan.

4 · Generate and inspect. Select Generate from design, or load GRBL G-code directly and choose Parse / simulate code. Open Toolpaths view to see feed/rapid motions. Watch warnings in the diagnostic log and job-health panel. An unsupported command or unsafe coordinate blocks export until corrected.

5 · Preview the actual removal model. Drag inside the 3D viewer to orbit, scroll to zoom, move the timeline to a specific stage, play cuts, or jump to Final. The preview carves a height-map with a selected flat/ball cutter. Grid resolution impacts surface detail. Round cuts use dense circle geometry and an exact-radius cutter footprint on the sampled grid. It is approximate, particularly on tiny contours and sharp corners.

6 · Verify and export. Export the validated .nc file (or save SVG/DXF geometry and a preview-only 3D STL) and load the .nc file into a machine sender compatible with your verified controller, such as Candle. This app does not connect to or command your machine. Verify your controller accepts the file, correct work coordinate system, safe Z travel, and direction by air-cutting first.

7 · Save / report issues. Save a .cncpro.json project; reload later to restore drawing and settings. Run Self-test in the diagnostic panel, then download a diagnostic report with errors and project settings to share if anything fails. Projects autosave to this browser when local storage is enabled.

File support: G-code: G0/G1/G2/G3 motions in the XY plane, G20/21 units, G90/91 distance mode, common M3/M4/M5 commands and G54 default workspace; advanced coordinate changes, probing, tool changes, exotic canned cycles and other planes are intentionally rejected. SVG: common paths/shapes, basic transforms through browser geometry APIs. DXF: LINE, LWPOLYLINE, CIRCLE, ARC (bulge polylines and DXF BLOCK/INSERT not supported). STL: top-visible height-field relief from closed triangle geometry, no undercuts, optional ball-nose raster rough/finish; STEP/IGES not supported in a standalone browser-only file.

Relief & Maps v4.1: STL and triangulated OBJ are projected from above as 2.5D reliefs, not freed 3D objects. Photos become artistic luminance height maps, not measured depth unless a calibrated depth map is supplied. Map images can be traced manually; local GeoJSON and Overpass road/building files can be read without network access. Roofs are preserved stock surrounded by lowered ground and roads. U.S. state outlines are approximate craft-scale boundaries. Avoid using Google Maps imagery without complying with its usage terms. All relief toolpaths are router-bit paths, not laser jobs.

Important: STL units are not defined in the STL format. CNC Pro asks for explicit relief dimensions/depth and projects mesh XY to a top-view height field. This is not general 3D machining. No machine movement or physical clearance can be guaranteed by an HTML simulator.
